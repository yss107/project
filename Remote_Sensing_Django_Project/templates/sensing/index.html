About the Dataset

The Major-TOM/Core-AlphaEarth-Embeddings dataset provides pre-computed embeddings for satellite imagery, enabling efficient remote sensing analysis and machine learning applications.

Available Splits:
Training Validation Test
View Dataset Details HuggingFace

Key Features

Powerful tools for remote sensing applications

HuggingFace Integration

Seamlessly access and work with the Major-TOM/Core-AlphaEarth-Embeddings dataset. Direct integration for efficient data loading.

  • Streaming support
  • Automatic caching
  • Split management
Advanced Search & Filter

Powerful filtering options to find specific satellite images based on various metadata attributes.

  • Grid cell search
  • Date range filtering
  • Cloud cover threshold
Analysis Tracking

Store and manage analysis results for satellite imagery with detailed metadata and confidence scores.

  • Result storage
  • Confidence tracking
  • Historical data
Embedding Vectors

Pre-computed 768-dimensional embeddings for efficient similarity search and machine learning tasks.

  • High-dimensional
  • Pre-computed
  • ML-ready
Geospatial Data

Store and visualize geographic coordinates with latitude/longitude support for spatial analysis.

  • Coordinate tracking
  • Grid cell system
  • Global coverage
Admin Interface

Full-featured Django admin panel for comprehensive data management and system configuration.

  • CRUD operations
  • Bulk actions
  • User management
