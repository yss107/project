About This Project

Remote Sensing Django Application

Project Overview

This Django application provides a comprehensive platform for working with remote sensing data, specifically designed to integrate with the Major-TOM/Core-AlphaEarth-Embeddings dataset from HuggingFace.

Purpose

The application serves as a bridge between the HuggingFace datasets ecosystem and a traditional Django web application, allowing users to:

  • Load and store satellite imagery metadata
  • Manage remote sensing data through a user-friendly interface
  • Perform and track analyses on satellite images
  • Organize data by various parameters and filters
  • Access data through both web UI and Django admin
