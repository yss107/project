About Major-TOM/Core-AlphaEarth-Embeddings

The Major-TOM/Core-AlphaEarth-Embeddings dataset is a comprehensive collection of satellite imagery embeddings designed for remote sensing applications.

Key Features:
  • High-quality satellite imagery embeddings
  • Pre-computed feature vectors for efficient analysis
  • Suitable for various remote sensing tasks
  • Accessible through HuggingFace Datasets library
Potential Applications:
  • Land cover classification
  • Change detection
  • Object detection and segmentation
  • Environmental monitoring
  • Agricultural analysis
Note: This project provides a Django interface for working with the dataset. You can load, store, and analyze satellite imagery data through the web interface and admin panel.
Getting Started
Loading Data

To load data from the HuggingFace dataset, you can use the provided utility functions in the sensing/utils.py module:

from sensing.utils import load_dataset_sample

# Load a sample of the dataset
samples = load_dataset_sample(split='train', num_samples=10)
